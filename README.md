# 🔥 Fire Detection App

Aplicación web que utiliza un modelo de clasificación de imágenes para detectar fuego en paisajes forestales.  
Permite subir una imagen, aplicar filtros de mejora y obtener una predicción en tiempo real.

---

## 🗂️ Dataset  
https://www.kaggle.com/datasets/alik05/forest-fire-dataset

---

## 🚀 Tecnologías
- Python 3.11+
- Django 4.2
- TensorFlow / Keras
- OpenCV
- Pillow

---

## 🛠️ Instalación y Ejecución (Django)

### 1️⃣ Clonar el repositorio
```bash
git clone https://github.com/SolMirsky/TP_Imagenes
cd TP_Imagenes/fire_detector
```

### 2️⃣ Crear entorno virtual y activarlo
```bash
python -m venv fire_env
fire_env\Scripts\activate  # Windows
```

### 3️⃣ Instalar dependencias
```bash
pip install -r requirements.txt
```

### 4️⃣ Ejecutar la app Django
```bash
python manage.py runserver
```

### 5️⃣ Abrir en el navegador:

 👉 http://127.0.0.1:8000/
